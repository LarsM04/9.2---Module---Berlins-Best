# Streetfood Berlin

**Categorie:** Eten en drinken  
**Gekozen locatie:** Markthalle Neun, Berlin  
**Teamleden:** Lars, Armin, Iris, Bilal

## Inhoud van deze repository
- `teamverslag.md`: afspraken en besluiten van het team
- `logboek/`: logboek per teamlid
- `onderzoek/`: onderzochte locaties en bronnen
- `ontwerpen/`: ontwerpen van de webpagina
- `website/`: de uiteindelijke webpagina

## Locatie
Markthalle Neun is een historische markthal in Berlin-Kreuzberg met verschillende eet- en drinkaanbieders, markten en food-events. De locatie is gekozen omdat studenten er verschillende soorten eten kunnen ontdekken en omdat de plek veel visuele mogelijkheden biedt voor een webpagina.

## Website
De website is gebouwd met HTML, CSS en JavaScript. De slideshow wordt zelf aangestuurd met JavaScript.
